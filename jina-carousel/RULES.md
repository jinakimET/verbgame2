# 영어지문 세계관 · 제작 규칙

인스타그램 시리즈 「영어지문 세계관」(@jina.ssam_english)의 제작 규칙입니다.
새 대화를 시작할 때 이 파일(또는 같은 내용의 노션 「제작 규칙」 페이지)을 먼저 읽고 작업합니다.

## 0. 채널 방향
- 수능 영어 지문을 어려워하는 학생에게 지문 뒤의 배경지식, 지문 전개 방식, 출제 원리를 보여 준다.
- 기획 의도: 이 채널을 구독하면 책을 읽는 효과가 난다.
- 플랫폼: 인스타그램 캐러셀. 얼굴 영상은 쓰지 않는다. 캐러셀에 음성은 넣지 않는다.
- 릴스는 캐러셀 중 지나쌤이 고른 장만 따로 만든다. 대본은 지나쌤 승인 → 지나쌤이 직접 음성 작업 → 효과·싱크 작업 순서.

## 1. 주제 선정
- CSV(data/suneung_sheet_by_question.csv)의 기출 주제 + CSV 밖에서 독해에 도움이 되는 철학·인문·사회·예술·과학·문화 주제를 직접 찾아서 고른다.
- 주제는 개념 단위로 잡는다 (예: "2025-33번"이 아니라 "주의 경제").
- 노션 「영어지문 세계관 · 주제 관리표」에서 주제와 상태를 관리한다.

## 2. 주제 캐러셀 (글라스모피즘)
- 규격 1080×1440 (3:4). 글라스모피즘(흐린 그라데이션 배경 + 반투명 유리 카드).
- 색은 jina-color-chips 칩을 편마다 돌려 쓴다. 보라 한 가지로 쏠리지 않게. (No.1은 27번 잉크 네이비·코랄)
- 구성 (페이지 번호는 넣지 않는다. 장을 따로 떼어 써도 되게):
  1. 표지: 고정 배치. 시리즈 번호(No.) + 대표 어휘 훅(예: "공짜 앱의 비밀") + 질문 한 줄 + 수능 문항 도장 마크(예: "2025 수능 33번 출제") + 오늘 읽을 개념
  2. 미니 퀴즈 ① (읽기 전): 궁금증을 만드는 4지선다. 정답은 본문에 나온다.
  3~. 본문: 생각해 볼까요 → 개념의 출발점(누가·언제·왜) → 핵심 개념 → 구조 → 수능 지문 연결 → 기출 단어 → 지나쌤 한마디 → 한 줄 정리 + 더 읽어 보기
  마지막. 미니 퀴즈 ② (읽고 나서): 앞 내용을 읽어야 풀 수 있는 수능식 문제
- 퀴즈 정답은 같은 장 오른쪽 아래에 작게 거꾸로 적는다.
- "다음 편" 예고는 장이 아니라 캡션에 쓴다.
- 지나쌤 한마디: 편마다 Claude가 질문을 하고, 지나쌤이 준 글을 그대로(말투만 최소한으로 다듬어) 넣는다. 지어내지 않는다.

## 3. 수준별 지문 캐러셀 (네오 브루탈리즘)
- 같은 주제를 하(중학, 40단어 안팎) · 중(고1, 50단어 안팎) · 상(고3, 60단어 안팎) 영어 지문으로 새로 쓴다.
- 구성: 표지 → (하 지문 → 해석) → (중 지문 → 해석) → (상 지문 → 해석) → 단어 정리 하 → 중 → 상 → 수준이 올라가면 달라지는 것
- 주요 표현은 아주 쉬워도 수준마다 6개. 지문 속 해당 단어에 형광 표시.
- 지문 장 3개, 해석 장 3개는 상자 크기를 똑같이 하고, 글이 짧으면 글씨를 키워 맞춘다.
- 색: 바탕 #F9EAD7, 굵은 검정 테두리 + 어긋난 그림자. 하 연두 #BFE23A, 중 노랑 #FFE164, 상 빨강 #E10600.

## 4. 내용 원칙 (정보 전달이 목적)
- 디자인 때문에 글을 줄여서 내용이 왜곡·치우침·부족해지면 안 된다. 글 양에 맞춰 카드를 늘리고, 넘치면 장을 나눈다.
- 사실(학자, 연도, 인용, 수치)은 편마다 검색해서 확인한 것만 쓴다. 확인 안 된 것은 넣지 않는다.
- 인용의 출처가 불확실하면 특정인의 말로 쓰지 않는다 (예: "2010년 온라인 댓글로 널리 퍼진 말").
- 원문을 보지 못한 지문의 흐름은 "이 주제의 글에 흔한 전개"라고 밝힌다.
- 기출 단어 장에는 CSV에서 원문 확인된 단어만 쓴다.
- 지어낸 지문은 "학습용으로 새로 쓴 글이며 수능 원문이 아님"을 밝힌다.

## 5. 디자인 원칙
- 여백: 내용이 적은 장일수록 글씨와 칸을 키워 화면을 고르게 채운다(내용이 화면의 약 90%까지). 제목은 최대 1.1배까지만 키운다.
- 제목이 본문보다 지나치게 튀지 않게: 제목 70~96, 본문 38~42 기준(제목:본문 약 2:1).
- 제목은 한 줄에 들어가면 한 줄로. 넘칠 때만 의미 단위로 줄바꿈.
- 형광펜(강조 박스)은 실제 글자 위아래에 같은 여백을 두어 가운데 정렬. 강조 구간과 일반 글자 사이는 띄운다.
- 문단 마지막 줄에 단어 한두 개만 남지 않게 줄을 다시 나눈다.
- 텍스트 넘침은 코드에서 assert로 막는다. 자동 줄바꿈은 측정된 폭 기준.
- 렌더 후 반드시 이미지를 직접 보고 확인한다.

## 6. 노션 라이브러리 (공유용 수업 자료)
- 메인: 「영어지문 세계관 · 수준별 지문 라이브러리」 안의 「회차 목록」 데이터베이스에 회차마다 한 페이지.
- 회차 페이지 구성: 개념 요약 → 배경지식 한 페이지 → 하·중·상(지문 → 해석 → 문장별 구문 분석 → 주요 표현 6개) → 수준 비교 → 확인 문제(정답은 토글) → 지나쌤 한마디 → 더 읽어 보기 → 출처
- 구문 분석은 지나쌤 「지문 분석」 스킬 형식: S(파랑 밑줄)·V(빨강 굵은 밑줄)·O(초록)·C(주황), [절], (전치사구), 뼈대(몇 형식), 끊어 읽기, 핵심 구문·어법 포인트.
- 확인 문제는 정답이 하나만 성립하는지 검토한다.
